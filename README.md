# Android XML ↔ XLSX Converter

Fully client-side HTML converter for Android translation archives.

- ZIP archive with `values*/*.xml` resources → consolidated XLSX
- consolidated XLSX → ZIP while preserving the source archive hierarchy
- visible workbook layout matches the supplied `All translations` reference
- unchanged ZIP round trips are byte-for-byte identical
- files never leave the browser

Open `dist/index.html` through a local web server, or use the published GitHub Pages URL.

For a legacy XLSX that was not generated by this converter, select its original ZIP as the reference when rebuilding. Generated workbooks carry a very-hidden round-trip payload and do not need a separate reference ZIP.

## Local preview

```powershell
py -m http.server 8765 --directory dist
```
